# Agent 质量修复记录

日期：2026-10-04。范围：此前展示中发现的语义过度概括、正文与声明脱节、引用来源丢失、长度与 JSON 截断、权限边界和 ReAct 可观测性。所有 Python 验证使用 Conda `pkb-agent`。以下是运行时修复，不是录屏答案改写。

当前结论：确定性的工程缺陷已修复，五段展示题已有符合要求的真实运行结果。复杂排障的根因与“最小方案”推断仍有模型复核漏检，尚不能称为所有语义问题均已解决。

## 实现

- **引用链**：文档和 chunk 读取均携带真实标题、来源与保存的版本信息；同一 chunk 的较短搜索预览不清空已读取的正文和来源。版本来源仅传递 `upstream_url/revision/sha256` 白名单，不从文档标题猜测。
- **目录分页**：按实际观察字符预算返回完整页面，游标按实际返回位置推进；不同目录页使用包含内容哈希的引用 ID，避免相同 offset、不同页大小覆盖证据。
- **正文与声明一致**：`claims[].text` 必须按顺序原样覆盖整个正文，只允许条目间空白。额外的“仅”、术语改写、调序或未声明的尾句都会被确定性校验拦截。该规则只证明两处文字一致，不证明声明被来源支持。异常的 `status/kind` 类型也会返回校验错误，不再抛出异常。
- **语义复核**：结构检查后，对完整正文、声明及本轮工具返回的原文增加一个无工具的模型复核调用。包括没有被候选引用的检索片段，以检查其中的反例。重点核对量词、适用条件、推断和正文声明覆盖；失败进入原有有界修复流程。
- **逐条证据核对**：复核放行必须覆盖每条声明，给出支持判定、简短证据评价和来源原文片段。程序核实支持片段来自该声明引用的来源，且确实逐字出现在本轮工具返回的正文中；缺项或伪造片段不放行。片段真实存在仍不等于其逻辑上支持声明，后者依赖模型判断。
- **拒答硬规则**：模型自由生成的 `insufficient_evidence.answer` 不直接发布。运行时生成证据边界说明，并在有实际权限拒绝时说明未获授权。这个规则阻止虚构结论藏在空 claims 的拒答里，无需相信另一个模型的判断。
- **复核失败处理**：复核输出无效、被截断、服务不可用或输入超限时，停止发布候选答案并记录 `semantic_review_unavailable`。保留结束原因、用量及有界协议诊断。核心 verdict 字段仍严格检查，未消费的附加字段不再使合法判定失败。
- **长度与 JSON**：明确字数要求和 `--max-answer-chars` 触发正文长度校验，超限要求重写完整答案；识别输出 token 耗尽，要求缩短完整 JSON，不补齐截断 JSON 伪装成功。不把用户名、字段等业务长度误识别成回答限制。
- **工具边界**：`--kb-only` 在服务装配前限定三种知识库工具，不需要网页搜索密钥。此选项仍使用模型、embedding 和知识库网络服务。
- **可观测性**：CLI 分别展示主模型决策轮次、同批工具动作和复核结果。多个工具不冒充多个反馈轮次，查询改写不计入主 Agent 轮次。语义复核用量计入总费用；关闭复核时标为 `structure_verified`。
- **模型协议**：保留模型接口要求的 `reasoning_content` 供下一轮工具请求使用；默认序列化、CLI、repr 和审计工件不导出它。复核专用档位与主 Agent 分开配置。
- **瞬态断连**：三种只读 RAG RPC 遇传输异常最多尝试三次，短暂退避；业务错误、认证错误及写操作不重试。日志不输出请求参数或可能含凭据的异常正文。

复核最终使用 `low`、16384 token 输出上限和 200000 字符输入上限。此前低档位曾耗尽 4096 和 8192 token；一次多文档检索累计 132892 字符也超过原来的 80000 上限。显式关闭 thinking 的对照测试漏过已知错误，故没有作为默认。调整后仍保留明确上限，不截取原文伪装审核完成；主 Agent 的推理模式不变。当前本地 `.env` 的三个非秘密覆盖键已同步，并用新的 Settings 实例确认生效；仅改 YAML 不足以更新已有环境覆盖。

DeepSeek 的默认推理档位及工具轮次回传要求已对照 [官方 Thinking Mode 文档](https://api-docs.deepseek.com/guides/thinking_mode/) 核验。API 参数支持不等于推理结果正确。

## 录屏边界

复核仍是模型判断，不能声称消除了幻觉、每一句都形式化证明正确，或一个案例证明总体水平。工具读取和复核会增加延迟；不要承诺固定演示时长。

可以展示自主选取工具、利用返回 ID 继续读取、证据不足时停止，以及出现超长或不支持断言时修正答案。ConfigMap 场景仍是公开文档上的假设判断，不是访问或修复真实集群。

录制命令与手动权限演示见 [Ghostty 录屏说明](ghostty-recording.md)。
